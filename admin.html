Guía rápida: cómo usar esta pantalla
  1. Pendientes es tu lista de tareas. Primero confirma las reservas nuevas: el cliente recibe el aviso.
  2. Cuando pase la hora de llegada, marca si el cliente llegó o no vino.
  3. La agenda es para consultar: toca una reserva para ver sus datos, cambiar su estado o cancelarla.
  4. En el plano de mesas eliges una hora y ves qué mesas están libres. Toca una mesa libre para reservarla por teléfono.
